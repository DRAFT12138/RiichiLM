# ロードマップ

RiichiLM の現在の機能と今後の優先事項です。優先順位は変更される場合があります。強さと長期学習の品質は別途評価します。

## 実装済み

- [x] 麻雀 Tokenizer、合法行動 trie、Qwen3 方策、Rust ルールエンジン。
- [x] 行動 token の教師あり学習、共有文脈学習、完全な checkpoint 復帰。
- [x] 自己対戦収集、Oracle Critic、KL 制御付き PPO、凍結対戦相手プール、RL ラウンド境界復帰。
- [x] 人間対 AI、四 AI 観戦、画面なしの対局。ローカル NTP checkpoint、カスタム重み、外部 LLM、ランダム戦略に対応。
- [x] 英中日の画面と文書、公開リポジトリと CI。

チェック済みは実装の存在を示します。既存の CPU・ブラウザーと AMD GPU 検証にはそれぞれ適用範囲があり、CUDA の独立した実行検証は未完了です。

## 近日公開：事前学習済み重み

## 実験と評価

- [ ] 勾配、活性値、実際のパラメーター更新、KL、エントロピー、Critic／優位度の健全性指標を追加し、観測コストを測る。
- [ ] 再現可能な入力で、共有文脈の長期スループット、数値挙動、学習品質を評価する。
- [ ] CUDA の独立インストール・実行とネイティブビルドの検証を拡充する。
- [ ] 負荷別の Web モデル遅延・メモリを測定し、卓での RL Actor 対応を検討する。
- [ ] 三言語の用語、アクセシビリティ、狭い画面のレイアウトを改善する。
- [ ] Oracle／PPO／KL の比較実験、長期自己対戦、凍結プールの候補昇格・入替評価を行う。
- [ ] 席を入れ替えた比較、不確実性、計算コスト、再現可能な評価手順を報告する。

学習・研究用です。学習データセット、評価データセット、非公開牌譜は配布しません。今後公開する重みのライセンスは別途明示し、コードは Apache-2.0 を維持します。学習には適切な利用権を持つ互換入力を用意してください。
