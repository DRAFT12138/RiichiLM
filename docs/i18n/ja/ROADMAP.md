# ロードマップ

RiichiLM の現在の機能と今後の優先事項です。優先順位は変更される場合があります。強さと長期学習の品質は別途評価します。

## 実装済み

- [x] 麻雀 Tokenizer、合法行動 trie、Qwen3 方策、Rust ルールエンジン。
- [x] 行動 token の教師あり学習、共有文脈学習、完全な checkpoint 復帰。
- [x] 自己対戦収集、Oracle Critic、KL 制御付き PPO、凍結対戦相手プール、RL ラウンド境界復帰。
- [x] 人間対 AI、四 AI 観戦、画面なしの対局。ローカル NTP checkpoint、カスタム重み、外部 LLM、ランダム戦略に対応。
- [x] 英中日の画面と文書、公開リポジトリと CI。

チェック済みは実装の存在を示します。既存の CPU・ブラウザーと AMD GPU 検証にはそれぞれ適用範囲があり、CUDA の独立した実行検証は未完了です。

## 事前学習済みベース重み

**50 万ステップの教師あり事前学習済みベースモデルの重みを Hugging Face で公開しました：[`Draft12138/RiichiLM-Base`](https://huggingface.co/Draft12138/RiichiLM-Base)**（`riichilm-base-500k.pt`、**CC-BY-NC-4.0**）。現在は **100 万ステップ（1M）** のベースモデル（`riichilm-base-1m.pt`）に向けて事前学習を継続しており、完了後に同じリポジトリで公開予定です。オープン重みの公開対象はこの教師あり事前学習ベースモデル 2 点（`500K` と `1M`）のみに限定され、後続の強化学習（RL）段階の成果物（RL 方策重みおよび関連する補助モデル）は公開範囲に含みません。今後の RL ロードマップおよび設計方針は現時点では公開していません。

- [x] [`Draft12138/RiichiLM-Base`](https://huggingface.co/Draft12138/RiichiLM-Base) に 50 万ステップベース重み（`riichilm-base-500k.pt`）、SHA-256 チェックサム、CC-BY-NC-4.0 ライセンス、モデル設定、読込手順を公開する。
- [x] 公開済みの 50 万ステップ Hugging Face ファイルを再ダウンロードして、SHA-256 検証、`weights_only=True` 読込、Web モデルカタログ解決、GPU（`cuda:0`）単局 `arena-evaluate` 実行を検証する。
- [ ] **100 万ステップ（1M）** の事前学習を完了し、`Draft12138/RiichiLM-Base` に `riichilm-base-1m.pt` と 1M モデルカードを公開して検証する。

利用手順は [README](README.md) と [50 万ステップ モデルカード](model-card-500k.md) を参照してください。学習・評価データセットは引き続き配布しません。推論用の重みだけでは、完全な学習再開に必要な optimizer、RNG、データカーソル、互換コーパスはそろいません。

## 実験と評価

- [ ] 勾配、活性値、実際のパラメーター更新などの学習健全性指標を追加し、観測コストを測る。
- [ ] 再現可能な入力で、共有文脈の長期スループット、数値挙動、学習品質を評価する。
- [ ] CUDA の独立インストール・実行とネイティブビルドの検証を拡充する。
- [ ] 負荷別の Web モデル遅延・メモリを測定する。
- [ ] 三言語の用語、アクセシビリティ、狭い画面のレイアウトを改善する。
- [ ] 席を入れ替えた比較、不確実性、計算コスト、再現可能な評価手順を報告する。

## 配布について

学習・研究用です。学習データセット、評価データセット、非公開牌譜は配布しません。オープン重みの公開対象は **CC-BY-NC-4.0** に基づく `500K`（公開済み）と公開予定の `1M` 教師あり事前学習ベースモデルに限定され、後続の RL 段階の成果物（RL 方策重みおよび関連する補助モデル）は含みません。コードは **Apache-2.0** を維持します。学習には適切な利用権を持つ互換入力を用意してください。
