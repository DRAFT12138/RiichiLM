# RiichiLM 50万ステップ モデルカード

## 概要

| 項目 | 内容 |
| --- | --- |
| モデル | RiichiLM 立直麻雀合法アクションポリシーモデル |
| 学習段階 | ランダム初期化した重みからの教師あり次アクション学習 |
| Optimizer update 数 | 500,000 |
| パラメータ数 | 101,477,120（約1億150万） |
| アーキテクチャ | Qwen3形式のデコーダー。16層、隠れ次元768、Attention head 12、Key/Value head 4 |
| 語彙数 | 1,024 token |
| 最大コンテキスト | 8,192 token |
| タスク | 公開されている局面履歴と合法アクション集合から、次の合法な麻雀アクションを予測 |

本モデルは立直麻雀に特化したポリシーモデルであり、汎用チャットモデルではありません。

## 学習規模

2026-10-24時点のコーパス記録には、4,585,517局、2,439,932,818件のアクション教師信号、9,024,927,373個の教師対象 token が含まれています。

500,000 update の終了時点で、学習進捗記録上の更新済みサンプル数は **151,877,118件** でした。処理したbatch数は24,000,000、勾配累積数は8です。

モデルは教師ありアクション目標を予測するよう学習します。合法アクション集合はtoken列とは別に渡され、ポリシーの出力を現在の状態で有効なアクションに制限します。

## 計算資源とソフトウェア

- アクセラレータ：NVIDIA GeForce RTX 3090 × 6（各24 GB）
- 並列方式：6 rank の分散データ並列（DDP）。記録されたホスト環境ではNVLinkを利用できません
- 精度：BF16混合精度。パラメータ、勾配、Adam状態はFP32
- 勾配累積：optimizer update ごとに8 microbatch
- 記録された学習時間：6回の学習attemptにおける学習フェーズの合計は約318.1時間、6 GPU換算で約 1,909 GPU時間 です。実行監視記録上の学習フェーズを集計しており、初期化、検証、checkpoint保存の時間は含みません。
- DDPソフトウェア環境の記録：NVIDIA driver 515.105.01、CUDA 11.7 toolchain、PyTorch 2.5.1、BF16対応。50万updateの学習には上記の6 GPU DDP環境を使用しました。

このrunは2026-11-16に500,000 optimizer updateへ到達しました。ランダム初期化から開始し、保存済みの学習状態から継続しました。事前学習済みQwen checkpointから開始したものではありません。

## 想定用途

プロジェクト互換のtokenizer、ルールエンジン、合法アクションインターフェースと組み合わせて、立直麻雀のポリシー推論に使用します。現在のプレイヤーに見える情報と、それ以前に見えている局面履歴に基づき、合法アクションから選択します。

## 制限事項

モデルの挙動は、学習牌譜の範囲や偏り、前処理の影響を受けます。対応する合法アクション制約と局面状態の実装とともに使用してください。このモデルカードは学習過程とアーキテクチャを説明するもので、モデル重みや学習データは含みません。
