# RiichiLM 50 万步模型卡

## 模型概况

| 项目 | 信息 |
| --- | --- |
| 模型 | RiichiLM 立直麻将合法动作策略模型 |
| 训练阶段 | 从随机初始化权重开始的监督式下一动作训练 |
| 优化器更新步数 | 500,000 |
| 参数量 | 101,477,120（约 1.015 亿） |
| 架构 | Qwen3 风格解码器；16 层，隐藏维度 768，12 个注意力头，4 个键值头 |
| 词表 | 1,024 个 token |
| 最大上下文 | 8,192 个 token |
| 任务 | 根据可见牌局历史和合法动作集合预测下一步合法麻将动作 |

这是面向立直麻将任务的策略模型，不是通用聊天模型。

## 训练规模

2026-10-24 记录的语料快照包含 4,585,517 场对局、2,439,932,818 条动作监督和 9,024,927,373 个受监督目标 token。

50 万步训练结束时，训练进度记录累计更新了 **151,877,118 个样本**。训练共处理 24,000,000 个 batch，梯度累积为 8。

模型学习预测受监督的动作目标。合法动作集合由 token 序列之外单独提供，用于将策略输出限制在当前状态下有效的动作中。

## 计算资源与软件

- 加速卡：6 张 NVIDIA GeForce RTX 3090，每张 24 GB 显存
- 并行方式：6 个 rank 的分布式数据并行（DDP）；记录的主机环境不具备 NVLink
- 精度：BF16 混合精度；参数、梯度和 Adam 状态使用 FP32
- 梯度累积：每次优化器更新累积 8 个 microbatch
- 训练耗时记录：六次训练 attempt 的训练阶段累计约 318.1 小时；按 6 张卡折算约 1,909 GPU 小时。该统计按运行观察器记录的训练阶段计算，不含初始化、验证和 checkpoint 保存阶段。
- DDP 软件环境记录：NVIDIA 驱动 515.105.01、CUDA 11.7 工具链、PyTorch 2.5.1，支持 BF16。50 万步训练使用上述六卡 DDP 环境。

该 run 于 2026-11-16 达到 500,000 次优化器更新。从随机权重开始，并通过已保存的训练状态继续推进；没有从预训练 Qwen checkpoint 开始。

## 预期用途

可在项目兼容的 tokenizer、规则引擎和合法动作接口中用于立直麻将策略推理。模型根据当前玩家可见的信息和先前可见的牌局历史，在合法动作中选择动作。

## 局限

模型行为会受到训练牌谱覆盖范围、牌谱特征及预处理方式的影响。使用时应配合匹配的合法动作约束和牌局状态实现。本模型卡介绍训练过程与架构，不包含模型权重或训练数据。

## 记录日期

该 run 于 2026-11-16 达到 500,000 次更新。语料规模数据对应 2026-10-24 的快照。
