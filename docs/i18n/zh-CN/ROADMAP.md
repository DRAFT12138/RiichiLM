# 路线图

本路线图重置 RiichiLM 的公开规划基线，只记录面向使用者的能力与可验证的后续事项，不搬运内部实验和历史训练日程。优先级可调整，不承诺发布日期或棋力等级。

## 已有代码能力

- [x] 麻将 Tokenizer、合法动作 trie、Qwen3 策略及 Rust 规则引擎。
- [x] 动作 token 监督训练、共享上下文训练及 checkpoint 恢复。
- [x] 自我对弈采集、Oracle Critic、KL 约束 PPO、冻结对手池及 RL 轮边界恢复。
- [x] 本地真人对战与四 AI 观战，各席独立选择 NTP、外接 LLM 或随机策略。
- [x] 英文、中文和日文界面及项目文档。

上述勾选表示代码能力，不代表竞技棋力或长期训练质量已验收。

## 1. 可复现的公开版本

- [x] 完成逐文件白名单，覆盖模型、训练接口、RL、通用运行／数据组件、Web、必要测试与资源。
- [x] 使公开 CLI、配置和依赖引用自洽；将当前何切评测输入改为可独立配置，避免隐式依赖不分发的私有题集。
- [x] 在三语 README 中说明自备语料格式及 checkpoint 使用条件；具体来源解析与处理保持私有。
- [x] 仅从导出树完成安装和实质回归；复用既有依赖环境，但不导入私有源码。覆盖模型构造、随机 Actor 往返、完整对局采集、PPO 更新、保存和新进程恢复。
- [x] 建立独立 Git 历史的公开仓库及公开 CI。
- [x] 在私有侧提供手动同步脚本，支持预览、明确管理文件、冲突处理及可复现导出；不自动同步或强推。

托管CI的实际执行及CUDA运行验证，与已完成的本地CPU／浏览器检查分别记录。

## 2. 改善实验体验

- [ ] 接入梯度、激活、实际参数更新、KL、熵及 Critic／优势的训练健康指标，并测量观测开销。
- [ ] 用贡献者自备输入及可复现合成样例评估共享上下文长期吞吐与数值行为。
- [ ] 扩大 CUDA 独立安装／运行及原生构建验证，清楚记录各平台证据。
- [ ] 测量真实模型 Web 延迟和内存；研究牌桌加载 RL Actor，不放宽加载校验或可见性边界。
- [ ] 持续改进三语术语、无障碍和窄屏布局。

## 3. 研究与评估

- [ ] 开展有对照的 Oracle／PPO／KL 消融和更长期自我对弈。
- [ ] 在持续运行中验证冻结对手池轮转、候选晋升和质量准入。
- [ ] 报告换座对比、不确定性、计算成本与可复现评估流程，不以冒烟测试或 loss 曲线推断棋力。

## 分发边界

仅供学习与研究。不分发训练数据、评测数据集、预训练模型、训练后的 checkpoint 或私有牌谱；请自行提供兼容输入。公开文档仅包括 README、ROADMAP、CONTRIBUTING 的中英日版本，以及必要许可／归属说明和引用的视觉素材。仓库 skill、AGENTS.md、内部设计、项目记忆、验收证据、归档、私有处理代码、密钥及私有 Git 历史均不导出。
