The files in this directory are the upstream Regular SVG set, copied unchanged.
The upstream LICENSE.md is included verbatim. The author dedicates the work to
the public domain under CC0: https://creativecommons.org/publicdomain/zero/1.0/.

The application layers the original tile faces over Front.svg and adds CSS depth,
hover/selection lighting, and layout. Back.svg is used for concealed tiles.
